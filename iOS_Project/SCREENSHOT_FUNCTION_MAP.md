# 截圖功能映射

## 主分頁

- `首頁`
  - 每日清單
  - 完成度
  - 快速入口
- `變美`
  - 護膚管理
  - 美白計畫
  - 美容預約
- `體態`
  - 運動管理
  - 塑型計畫
  - 體重體脂
  - 飲食記錄
  - 養生健康
  - 體態相簿
- `成長`
  - 閱讀追蹤
  - 成長筆記
  - 週計畫
- `我的`
  - 個人設定
  - 客製化
  - 資源庫
  - 成就徽章
  - 數據匯出

## 子頁對照

- `護膚管理`
  - 護膚步驟：勾選、指定產品、自訂步驟
  - 保養品：列表與新增
  - 膚質追蹤：膚質、困擾、備註
  - 教程連結：外部教學
  - 打卡歷史：心得紀錄
  - AI 建議：本地規則推薦
- `美白計畫`
  - 產品使用紀錄
  - 色號追蹤
  - 前後對比照空狀態
- `體態數據`
  - 以體重體脂頁承接
- `閱讀追蹤`
  - 書名
  - 作者
  - 外部連結
  - 備註
- `資源庫`
  - 小紅書 / YouTube / Instagram / 網頁
  - AI 智能分析
  - 分類篩選
  - 智能推薦
